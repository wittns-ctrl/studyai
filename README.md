# studzAi — Personalized Learning Platform

Landing site inspired by [Nubien](https://nubien.framer.website/) with SRS-aligned educational content.

## Run locally

```bash
cd "C:\Users\HP\OneDrive\Documents\studz"
npm install
npm run dev
```

Open http://localhost:5173

- **Favicon:** `public/favicon.svg`
